# Controle Comercial de Teatros

Primeira versao navegavel do sistema privado para controle comercial de contatos com teatros no Brasil.

## Como abrir

Acesse pelo GitHub Pages depois de ativar a publicacao do repositorio.

## Contas iniciais

- Operador: `operador@teatros.com` / `operador123`
- Operadora Sudeste: `sudeste@teatros.com` / `sudeste123`

## O que esta incluido

- Login privado com perfis de administrador e operador
- Dashboard do operador como fila de contatos a fazer
- Filtros por palavra-chave, intervalo de proximo contato e relevancia
- Cadastro simplificado de teatros com campos em portugues
- Ate dois responsaveis cadastrados diretamente no teatro
- Estados e principais cidades ja cadastrados
- Registro de contato realizado a partir do dashboard ou do teatro
- Lista de teatros
- Relatorios administrativos simples
- Persistencia local no navegador

## Observacao tecnica

Esta entrega e uma primeira versao funcional para validar fluxo, telas e modelagem. A proxima etapa natural e migrar a persistencia local para PostgreSQL com autenticacao real no backend.
